Privacy Policy

Mohafiz Studio · last updated 12 November 2026

Mohafiz Studio is a private tool used only by the owner of the Watan Ke Mohafiz channel to publish videos to the owner's own YouTube channel and Instagram account. It is not offered to the public and has no other users.

What information it uses

  • The owner's own account access. When the owner connects YouTube (through Google sign-in) and Instagram (through Meta's login), the tool receives access tokens for those accounts. They are used only to upload the owner's videos, set their thumbnails, read basic channel statistics, and read and reply to comments on the owner's own videos.
  • Public comments on the owner's videos. The tool reads comments viewers post on the owner's videos (the commenter's public display name and the comment text) so the owner can reply. It does not collect anything else about viewers and does not build profiles of anyone.

YouTube API Services

Mohafiz Studio uses the YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Where information is kept

Access tokens and settings are stored on the owner's own phone and, encrypted, as secrets in the owner's private GitHub repository, which runs the owner's publishing jobs. Comment text is processed only to draft replies and is not stored beyond what is needed to remember which comments were answered. Nothing is sold, shared with advertisers, or given to anyone else.

How long it is kept, and how to remove it

Information is kept only while the owner uses the tool. The owner can delete it at any time from the tool's settings. Access to a Google account can also be removed at any time on the Google security settings page, and access to an Instagram account in Instagram's settings under Website permissions → Apps and websites.

Children

The tool is not used by or directed at children.

Changes and contact

Any change to this policy will be posted on this page. Questions can be sent to the channel owner through the contact email shown on the Watan Ke Mohafiz YouTube channel's About page.
